
# Student Pass/Fail Prediction

## Project Description

An end-to-end Machine Learning project that predicts
student pass/fail outcomes using learning-related data.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib
- Streamlit
- Jupyter Notebook

## Machine Learning Models

1. DummyClassifier
2. Logistic Regression
3. Random Forest Classifier

## Project Features

- Dataset inspection
- Missing value handling
- Feature selection
- Data preprocessing
- Train/test split
- Model training
- Model evaluation
- Model saving and loading
- New student prediction
- Streamlit interface

## Installation

Install dependencies:

pip install -r requirements.txt

## Run Jupyter Notebook

jupyter notebook

Open student_prediction.ipynb and run all cells.

## Run Streamlit Application

streamlit run app.py

## Responsible Use

This project uses synthetic classroom data.
Predictions are for educational demonstration only
and must not be used to judge or penalize real students.
